# agentic-stack v0.19.2

Content release, 2026-09-28. The portable-brain work that matured on
`feature/portable-brain-profiles` lands on master: managed fleet rollout, the
v0.20 spec addendum (folded), root adapters, the Ralph loop kit, guard
dispatch, and the fold-branch tool. Additive — upgrading preserves project
instructions and user memory.

## Added

- **Managed fleet rollout** — manifest-driven `fleet audit` and transactional
  `fleet upgrade` with explicit workspace ownership, trusted verification,
  preservation snapshots, and automatic per-workspace rollback
  (`tests/test_fleet.py`).
- **Artifact registry + validator** — a managed portable-brain artifact
  registry with `validate_extracted_artifacts.py`; `doctor` runs it and
  reports missing or invalid managed artifacts. `upgrade` refreshes
  registry-owned protocols, schemas, templates, and tools.
- **v0.20 spec addendum, folded** — subgoal acceptance criteria and
  requirement-to-check traceability (§2.1), skill-level evals with one
  quarantine chain (§2.3), federation reconciled to the private content
  source (§2.6), unified human-gate queue (§2.8).
- **Root adapters + Ralph loop kit** — `AGENTS.md`/`CLAUDE.md` for the repo,
  and `scripts/ralph/` with an agent-agnostic loop contract: any CLI
  (`--tool`/`RALPH_TOOL`, autodetect), prompt on stdin, per-tool flag table,
  `<promise>COMPLETE</promise>` stop signal.
- **Stele-first guard dispatch** — framework `pre_tool_call.py` imports the
  user-scope brain's rule instead of copying it; fail-open by documented
  contract.
- **`fold_branch.py`** — fold a dependent ticket branch into the branch
  carrying its files (`check` / `fold` / `verify`), extracted from DDI-1035.
- **ztk savings discipline** — the skill now carries the measured rules:
  pipe container output to a file and tail it, prefer Read over `cat`,
  scripts print summaries.

## Upgrade

```bash
agentic-stack upgrade --dry-run
agentic-stack upgrade --yes
```

Additive: existing memory, skills, adapters, and loop contracts are
untouched. The managed block merges into `.agent/AGENTS.md` without
touching project instructions. Projects that never adopted the fleet
surface change nothing.
